Actúa como un Product Manager senior especializado en metodologías ágiles y MVPs. Necesito que redactes un Documento de Requisitos de Producto (PRD) detallado para el MVP de una aplicación de gestión de espacios y cuidado del hogar. 

La app está dirigida a personas desorganizadas que buscan control de su entorno.

El MVP debe incluir estrictamente el siguiente alcance simplificado:
1. Autenticación básica de usuarios (Email/Password).
2. Módulo de Espacios: Crear, editar y eliminar zonas del hogar (ej. Cocina, Trastero).
3. Módulo de Inventario de Objetos: Añadir un objeto con nombre, una foto opcional, descripción corta y asignarlo a una zona. Incluir un buscador simple por texto.
4. Módulo de Plantas: Añadir una planta, definir su intervalo de riego en días y ver una lista de "tareas pendientes" con un botón para marcar como regado.

Por favor, estructura el documento con las siguientes secciones:
- Introducción y Objetivos del MVP (Enfocado en solucionar la pérdida de tiempo buscando cosas y el olvido de tareas).
- Historias de Usuario principales (Formato: "Como [usuario], quiero [acción] para [beneficio]").
- Requisitos Funcionales clave detallados por módulo.
- Criterios de Aceptación básicos para cada función.
- Restricciones y exclusiones fuera del MVP (Sin integraciones complejas, sin IA, sin multiusuario).

Usa un lenguaje claro, técnico pero accesible, listo para entregar a un equipo de desarrollo de software.
